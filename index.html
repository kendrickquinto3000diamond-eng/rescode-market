PG APIKEY

QRIS buat tokomu sendiri, lewat satu request.

Ambil API key di menu PG APIKEY dalam aplikasi. Kirim nominal, terima gambar QRIS dan total yang harus dibayar. Setelah lunas, status berubah dan callback dikirim ke URL kamu.

  • Auth header X-API-Key
  • Minimal Rp1.000 per transaksi
  • Expired QR kedaluwarsa otomatis
  • Callback opsional lewat callback_url
POST /api/pg/v1/qris/create GET /api/pg/v1/qris/status/:reference

Cara kerja
